# Atlas Realty Suite — Demo inmobiliaria

Demo interactiva del sitio inmobiliario, el inventario y el CRM.

Al habilitar GitHub Pages, estará disponible en:
https://christianjva0-wq.github.io/atlas-realty-suite-demo/

Los archivos son HTML, CSS y JavaScript estáticos. Para probar localmente, sirve esta carpeta con un servidor HTTP.

**Aviso:** es una demostración. Los contactos y propiedades son ficticios; los cambios se guardan solo en el navegador de cada visitante. No ingresar datos reales de clientes.
